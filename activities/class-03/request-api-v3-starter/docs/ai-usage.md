# Uso de IA — Request API (clase 03)

## Asistencia en el desarrollo

Esta aplicación fue desenvolvida con la ayuda de herramientas de IA para:
- Generación de plantillas de código boilerplate
- Sugerencias de mejores prácticas para APIs REST
- Documentación de contratos HTTP

## Casos de uso de IA

1. **Diseño de endpoints**: Brainstorming de rutas y métodos HTTP
2. **Validación de esquemas**: Revisión de validaciones de entrada
3. **Formato de respuestas**: Estándarización de errores y formatos de éxito
4. **Refactoring**: Mejoras en la estructura del código existente

## Limitaciones

- Revisar siempre el código generado por IA en busca de seguridad
- Las lógicas de negocio críticas deben ser revisadas manualmente
- La IA puede sugerir patrones desactualizados

## Recomendaciones

- Usar IA como asistente, no como autoridad definitiva
- Mantener el código bajo revisión humana constante
- Documentar qué partes fueron asistidas por IA para futura mantenimiento
